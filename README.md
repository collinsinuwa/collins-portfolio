# Collins Inuwa: Student Portfolio and Academic Planner

Term project for COS 106 (Introduction to Web Technologies), MIVA Open University. Built with HTML, CSS and JavaScript only.

## Structure
- `index.html`, `about.html`, `projects.html`, `planner.html`, `contact.html`: the five required pages
- `quiz.html`, `landing.html`: demo pages linked from the Projects page
- `css/style.css`: one external, responsive stylesheet with light and dark themes
- `js/`: `main.js` (theme, menu, animation), `planner.js`, `contact.js`, `projects.js`, `quiz.js`
- `img/`, `media/`: photo, project screenshots, voice intro (MP3 and OGG)

## Brief checklist
Homepage (name, photo, welcome, nav, bio) | About (education, aspirations, skills table, hobbies) | Projects (3 projects, descriptions, images, links) | Planner (add, complete, delete) | Contact (required fields, valid email, digits-only phone) | Semantic HTML, form, table, images, links, lists, audio | Flexbox and Grid, transitions, responsive | Events, DOM, validation, arrays and functions
